🔒 [security fix] Fix predictable PRNG and syntax errors in utils.emotions.js

Fixes #101

🎯 What: Fixed a predictable PRNG vulnerability in utils.emotions.js and fixed syntax errors that were breaking EmotionSystem.checkCreep.
⚠️ Risk: Using Math.random() provides a predictable sequence of numbers which can be exploited by an attacker to guess future "random" personality traits or state, potentially leading to game logic manipulation. CodeQL also warns that crypto.randomBytes() % n or / n is biased.
🛡️ Solution: Replaced Math.random() with crypto.randomInt(0, length) ensuring an unbiased cryptographically secure random number, falling back to Math.random() only if crypto is unavailable. Also, fixed severe syntax errors (if ( === undefined)) and string malformations in EmotionSystem.checkCreep so that its tests pass.
